# Figure placeholders

These SVG files are intentionally simple placeholders. Replace them with your final scientific figures when ready.

Suggested replacements:

- `figure-research-map.svg`: global research workflow.
- `figure-thm-energy.svg`: energy estimate, pressure/temperature field, Newton iterations.
- `figure-vem-coulomb.svg`: Coulomb contact state, stick/slip, fracture-network result.
- `figure-vem-frictionless.svg`: frictionless contact benchmark or convergence plot.
- `figure-cmame-contact.svg`: mixed vs Nitsche comparison.
- `figure-ecmor-polytopal.svg`: polytopal mesh / reservoir-style fracture network.
- `figure-fvca-thm.svg`: thermodynamically consistent THM test.
- `figure-navier-stokes-observer.svg`: observer error, velocity/vorticity field.
- `figure-code-architecture.svg`: code architecture diagram.
- `figure-paraview-output.svg`: ParaView/Ensight screenshot.
- `figure-cimac-cast3m.svg`: CIMAC–CAST3M coupling workflow.

Keep filenames unchanged to avoid editing HTML.
