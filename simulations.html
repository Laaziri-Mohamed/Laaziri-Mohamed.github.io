WaveEvolver — Nonlinear wave propagation

GPU-accelerated solver for nonlinear wave equations on curved backgrounds. The video above shows soliton scattering in a Schwarzschild geometry, computed using pseudo-spectral methods with adaptive time-stepping.

Python · JAX GitHub Documentation MIT License

QuantumGraph — Spectral visualization

Interactive visualization of eigenfunctions on quantum graphs. Computes spectral data via finite-element methods and renders real-time animations of wavefunction dynamics on combinatorial and metric graph structures.

JavaScript · D3.js · WebGL GitHub Live demo

TopoClassify — Topological invariant computation

Numerical computation of Chern numbers, winding numbers, and Z₂ invariants for tight-binding Hamiltonians on arbitrary lattice geometries. Includes routines for generating phase diagrams and tracking gap closings.

Julia GitHub Documentation

RGFlow — Renormalization group integrator

Numerical integration of renormalization group equations for scalar field theories. Tracks fixed points, computes critical exponents, and visualizes flow trajectories in coupling-constant space across various dimensions.

C++ · Python bindings GitHub
